# Lock Final as a published snapshot

Lock Final publishes the current Chapter Scene Assembly as the current Final Chapter Scene snapshot. The assembly remains editable as a draft afterward, and locking again replaces the current published final with a new snapshot while preserving enough lineage to understand which empty scene, assets, prompt, references, and assembly state produced it.

**Considered Options**

- Make Lock Final freeze editing: simple status semantics, but it blocks normal iteration after review.
- Treat Lock Final as publishing a snapshot: supports iteration while keeping the current chapter deliverable stable until the author publishes a replacement.
