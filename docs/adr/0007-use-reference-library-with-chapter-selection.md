# Use Reference Library with chapter reference selection

Reference images are owned by a shared Reference Library, while each Chapter Scene Package owns only the selection of references used for that chapter. This keeps reusable visual assets such as Character IP references and style anchors available across chapters without making chapter prompts depend on hand-entered image ids.

**Considered Options**

- Chapter-local uploads only: simpler for a first screen, but duplicates recurring character and style references across chapters.
- Shared Reference Library with chapter selection: adds a library surface, but gives visual assets one reusable source while preserving chapter-specific prompt context.
