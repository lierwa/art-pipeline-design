# 猫角色画法参考板来源

## 目的

这张参考板用于修正团团下一版画法，不用于直接复制素材。

重点观察：

- 胡须：用 2-3 条短线作为猫的符号，不用复杂毛发线。
- 尾巴：用大块轮廓或单根圆弧表现，不画波浪毛边。
- 挎包：按平面贴片处理，减少穿插线和绕体结构。
- 比例：大头、短身、低重心、短手短脚，靠轮廓和姿态变可爱。
- 线条：平面二维外轮廓优先，内部结构线越少越好。

## 对团团下一版的直接约束

- 必须保留胡须，而且胡须应成为猫脸识别的一部分。
- 尾巴不要再用波浪毛边。用圆弧或团块，最多一条轮廓线。
- 挎包不要强行转透视。正面/3-4 视角下用一条平面斜带 + 一个贴片小包即可。
- 不再追求“结构信息完整”。小尺寸游戏猫应该是平面符号，不是体块说明图。
